Privacy Policy

Last updated: 2026-09-11

videoMaker is a personal, single-operator automation project. It is not a public product, has no public sign-up, and no third party ever creates an account with it or authorizes it. This policy exists because Google's OAuth consent screen requires one for apps that request YouTube upload access, even for a personal-use tool like this one.

What this app accesses

videoMaker uses the YouTube Data API's upload scope (youtube.upload) for exactly one purpose: uploading videos that its operator rendered locally to a single YouTube channel that the operator owns. It does not read, access, or store any other user's YouTube data, and it does not access any Google account other than the operator's own.

What data is stored

The only data this project stores is data about its own operation: artist names, song titles, streaming/view-count metrics pulled from public APIs (Last.fm, YouTube), rendered video files, and publish records. None of this is personal data belonging to a third party or to anyone who has authorized this app — because no one other than the operator ever does.

Data sharing

This project does not sell, share, or transmit any data to third parties beyond the services it directly integrates with (Supabase for storage/database, YouTube for publishing, Last.fm for chart data).

Contact

Questions about this policy can be sent to the contact address listed on the project's GitHub repository.
